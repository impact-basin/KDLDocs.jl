API Reference

Module KDLDocs

KDLDocs — Module
KDLDocs

A parser for the KDL document language. Parse with kdl (or the @kdl_str macro), then navigate the result with KDLNode:

using KDLDocs

doc = kdl"node example=#true { foo 1 2 3; bar 4 5 6; }"
doc.node                 # the child node `node`
nameof(doc.node)         # :node
doc.node[:example]       # true
doc.node.foo[1]          # 1
arguments(doc.node.foo)  # [1, 2, 3]
Tuple(nameof.(@query doc top() > []))  # (:node,)

Nodes

KDLDocs.KDLNode — Type
KDLNode

A node in a parsed KDL document.

A node has:

  • name: its name – a Symbol for a bare identifier, a String for a quoted or raw string, and nothing for a document root (the unnamed container of top-level nodes);
  • arguments: an ordered Vector of positional argument values – duplicates and order are preserved;
  • properties: an OrderedDict of key => value pairs (rightmost wins);
  • children: an ordered Vector of child nodes – duplicates and order are preserved.

Reach the collections with arguments, properties and children, and the node's own name with nameof. k.name reaches a child, k[1] an argument by position, k[:key] a property value (missing when absent), and name in k tests argument membership. show serialises a node back to KDL.

Collections

KDLDocs.arguments — Function
arguments(k::KDLNode)

The ordered positional arguments of k.

KDLDocs.properties — Function
properties(k::KDLNode)

The properties of k, as an OrderedDict of key => value.

KDLDocs.children — Function
children(k::KDLNode)

The children of k, as an ordered Vector{KDLNode} in document order. Duplicate names are kept; each child knows its own name via nameof.

Parsing

KDLDocs.kdl — Function
kdl(x)

Parse x into a KDLNode, or throw KDLParseError if x is not valid.

x may be a String or an IO; the latter will be read in full.

KDLDocs.@kdl_str — Macro
@kdl_str "..."

Parse the KDL document in the string literal at macro-expansion time. A non-standard string literal passes Julia escape sequences through unchanged apart from the escaped quote, so terminate nodes with a semicolon or use the triple-quoted form for a multi-line document.

KDLDocs.kdl_read — Function
kdl_read(path)

Parse the KDL document stored in the file at path.

KDLDocs.KDLParseError — Type
KDLParseError(msg)

Raised when a KDL document cannot be parsed, or violates a semantic rule of the specification (reserved identifier, invalid escape, multi-line string structure, disallowed code point, ...).

Navigating and reading

Base.nameof — Method
nameof(k::KDLNode)

The name of node k: a Symbol for a bare identifier, a String for a quoted or raw string, or nothing for a document (the unnamed root).

Base.getindex — Method
k[i::Integer]

The i-th positional argument of k.

Base.getindex — Method
k[key]

The value of the property key of k, or missing when absent. key may be a Symbol or a String, and the two forms name the same property.

Base.getproperty — Method
k.name

The child node named name. For duplicate names, the last occurrence.

Base.propertynames — Method
propertynames(k::KDLNode)

The child names of k, as a Tuple of unique names in document order. Drives tab completion on a parsed node.

Base.in — Method
x in k::KDLNode

Whether x is one of the positional arguments of k. Membership uses isequal, so missing in k is false and NaN in k works.

Base.haskey — Method
haskey(k::KDLNode, i)

Whether k has a child or property named i. Positional arguments are unnamed; test them with i in k.

Mutating

Base.setindex! — Method
k[i::Integer] = v

Replace the i-th positional argument of k.

Base.setindex! — Method
k[key] = v

Set the property key of k to v. A missing value is rejected, since KDL has no missing value.

Base.setproperty! — Method
k.name = node

Add or replace the child node named name, giving node that name.

Base.push! — Method
push!(k::KDLNode, v)

Append the positional argument v to k, returning k.

Base.empty! — Method
empty!(k::KDLNode)

Remove all arguments, properties and children of k, returning k.

Base.merge — Method
merge(j::KDLNode, k::KDLNode)

A new node combining the arguments, properties and children of j and k. Arguments and children are concatenated; properties are merged with k winning on clashes, and the result takes k's name (right operand wins, as Base.merge does for dictionaries).

Base.merge! — Method
merge!(j::KDLNode, k::KDLNode)

Merge k into j in place and return j. As with merge, k's name wins.

Querying

KDLDocs.@query — Macro
@query doc query
@query query
@query doc begin query1; query2; ... end
@query begin query1; query2; ... end

Query a KDL document with a selector written as a Julia expression. With a document, the result is a Vector{KDLNode}; without one, the macro returns a callable KDLQuery. A begin ... end block compiles each expression and returns a tuple of results in the same shape.

The selector surface language follows KQL (> child, >> descendant, + next sibling, ++ later sibling, || union), with Julia values:

@query doc m3 > l1
@query doc lola > bundle[url ^= "https://pds-geosciences"]
@query doc diviner > [] + []
q = @query top() > m3
q(doc)
m3, lola = @query doc begin
    top() > m3
    top() > lola
end

Differences from KQL: %= is ends-with (KQL's $= cannot be written in Julia), type(...) replaces (tag)/tag(...), and values use Julia literals (true, false, nothing, Inf, NaN, numbers, foo for a Symbol, "foo" for a String). A String in query position is a quoted node name or value; use query"..." or query(doc, str) when the selector itself is a string. Type-annotation matchers are rejected until KDLNode retains annotations.

KDLDocs.KDLQuery — Type
KDLQuery

Represents a compiled KDL query (c.f. a Regex() object. The query object is callable on KDL documents, e.g. q(doc), and can be passed to query.

Queries can be constructed from

  • A string: KDLQuery(str),
  • A string literal: query"..." or $query`...`$,
  • An expression in the Julia AST via @query

The latter two avoid reparsing.

KDLDocs.KDLQueryError — Type
KDLQueryError(msg[, pos])

Raised when a query cannot be parsed or violates a query-language rule. pos is the byte offset into the query string, or 0 when the query was written as a Julia expression.

KDLDocs.query — Function
query(doc::KDLNode, selector)
query(doc::KDLNode, q::KDLQuery)

Run a query against doc. selector may be a query string or a compiled KDLQuery; the result is a Vector{KDLNode} in document order, with duplicate matches removed by node identity.

KDLDocs.@query_str — Macro
query"selector"
query`selector`

Parse a query string at macro-expansion time and return the resulting callable KDLQuery literal, for use with query(doc, ...) or by calling the result:

query"top() > m3"(doc)

Non-standard string literals do not interpolate, so $ is passed through to the query parser rather than expanded; build dynamic queries with query(doc, str) instead.

KDLDocs.@query_cmd — Macro
query`selector`

Command-literal form of query"...".
